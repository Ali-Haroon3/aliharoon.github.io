Game support

For a rule or puzzle hint, open the question mark in a puzzle. Settings lets you replay the practice board.

Where is my progress?

The game saves completed puzzles, current moves, settings and daily records on this iPhone. Deleting the app can remove its save.

Report a problem

Use the developer’s public game issue tracker. Include the game title, puzzle number or daily date, iOS version and the move that caused the problem. Issues are public. Keep private details out of the report.
